# 🍕 PizzaHub – Full Stack Pizza Delivery & Restaurant Management Platform

PizzaHub is a modern full-stack pizza delivery and restaurant management platform built using the MERN stack. It provides a complete customer ordering experience along with a powerful admin dashboard for managing pizzas, inventory, orders, coupons, reviews, and analytics.

🟢 **100% Pure Vegetarian Pizza Platform**

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/pizzahub.git
```

---

## Backend Setup

```bash
cd backend

npm install

npm run dev
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
